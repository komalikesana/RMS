A full-stack Restaurant Management System that allows users to seamlessly interact with a restaurant’s offerings—from browsing the menu and booking tables to managing carts and completing payments. Admins have full control over menu and offer management.

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript

Backend: Node.js, Express.js

Database: MongoDB

🚀 Features
👤 User Features
Sign up and log in securely

Browse and search the menu

View current offers and discounts

Add food items to the cart with quantity control

Book tables or event halls for specific dates and times

Make online payments (mock integration)

🛠️ Admin Features
Add, update, and delete menu items

Create and manage offers

View bookings and customer activity
